## P0 — обрезка теней и выступающих иллюстраций

Общая причина: контейнер контента и карточки режут всё, что выходит за бокс. В макете иллюстрации специально вынесены за верх карточки, тени живут снаружи панели.

### GAP-001 — контентная колонка режет тени и низ экрана

**Где:** все экраны с `DashboardLayout`
**Макет:** тени карточек и бейджа видны целиком; нижние блоки (план дня на главной, последняя линия карточек в магазине) входят в кадр.
**Приложение:** `.dashboard-shell__content` — `overflow-x: hidden`, `overflow-y: auto`, padding 32. Внутренний скролл на `100vh`-шелле. Тень `box-shadow` карточек и `ShopCartBadge` обрезается по краям колонки. На главной блок «Ритм дня» уходит под fold и не попадает в первый кадр.

**Код:** `src/components/layout/DashboardLayout/DashboardLayout.scss`
**Цель:** дать теням запас (padding / `overflow: visible` по оси X), не клипать drop-shadow. Вертикальный скролл не должен отрезать нижнюю тень последнего блока.

### GAP-002 — ShopProductCard обрезает иллюстрацию

**Где:** `/game/shop`
**Макет (`2272:4352`):** карточка **без** `overflow: hidden`. Иллюстрация `176×140`, `top: -18px` — суп/тарелка выступают над верхней кромкой. Есть `drop-shadow`.
**Приложение:** `.shop-product-card { overflow: hidden }`. Картинка тоже `top: -18px`, но клипается по рамке карточки.

**Код:** `src/components/game/ShopProductCard/ShopProductCard.scss`
**Цель:** overflow только у текстового блока (как в макете `Product content overflow-clip`), иллюстрация и тень снаружи.

### GAP-003 — PropertyCard обрезает изометрию

**Где:** `/game/home`
**Макет (`2254:3832`):** карточка без clip; иллюстрация `top: -24px`, `154px` высоты. Комната сидит поверх верхней кромки.
**Приложение:** `.property-card { overflow: hidden }`, img `top: -24px`. Модель обрезана по бордеру.

**Код:** `src/components/game/PropertyCard/PropertyCard.scss`
**Цель:** тот же приём, что GAP-002.

### GAP-004 — модалка действия: иллюстрация должна выступать вверх

**Где:** модалка «Кино в кинотеатре» (`2214:2643` и соседние style-фреймы)
**Макет:** изометрия кинозала стоит **над** скруглением модалки, тень модалки целая.
**Приложение:** `.action-details__image` в ограниченном боксе; `overflow: hidden` у карточек/модалки. Нужно сверить `ActionDetailsModal` / `Modal` на clip.

**Цель:** выступающая иллюстрация + видимая тень, без обрезки по overlay padding.

## P1 — неучтённые / нулевые состояния

В макете почти все экраны — «счастливый» filled. Пустые состояния в коде есть частично, но часто показывают нули вместо empty UI.

### GAP-010 — бейдж корзины при 0 товарах

**Где:** `/game/shop`
**Макет:** `ShopCartBadge` (`2281:4614`) — только filled: «3 товара / 2 950 ₽», ширина 240×56. Отдельного empty-варианта нет.
**Приложение:** бейдж всегда виден: «0 товаров 0 ₽», ширина ~160px.

**Код:** `src/components/game/ShopCartBadge/ShopCartBadge.vue`
**Цель:** empty ≠ нули. Варианты: скрыть суммы и счётчик, оставить только иконку; либо не показывать бейдж, пока корзина пуста. Не выводить «0 ₽».

### GAP-011 — дроер корзины: итог 0 ₽ и disabled checkout

**Где:** дроер при пустой корзине
**Макет:** только filled (`2283:4608` / экран `2286:4645`): список, «Итого 3 100 ₽», «Перейти к покупке». Пустого кадра нет.
**Приложение:** текст «Корзина пока пуста», но футер всё равно с «Итого 0 ₽» и неактивной кнопкой.

**Код:** `src/components/game/ShopCartDrawer/ShopCartDrawer.vue`
**Цель:** в empty не показывать нулевую сумму. Кнопку оформления скрыть или заменить. Дроер в макете — плавающая панель 400×720, в коде full-height 360px dock — отдельный визуальный долг (GAP-012).

### GAP-012 — геометрия дроера корзины

Макет: overlay на контенте, панель 400×720, скругление, не на всю высоту.
Приложение: `position: fixed` на весь viewport, ширина 360, без скругления слева.

### GAP-013 — работа: безработный + «Уволиться»

**Где:** `/game/work`, фрейм `2322:5097`
Макет сам показывает «Безработный» и кнопку «Уволиться» — это ошибка макета, не копировать.
**Цель:** без работы не показывать «Уволиться». Empty текущей должности: только статус, без quit.

### GAP-014 — недвижимость: статус «Можно улучшить» всегда

**Где:** `/game/home`
Макет и приложение всегда рисуют зелёный чип. Нет состояния «максимальный уровень / уже это жильё / нельзя улучшить».
**Цель:** чип только когда апгрейд реально доступен; иначе другой статус или пусто.

### GAP-015 — старт: поле возраста только во взрослом режиме

**Где:** `/` vs `2206:2011`
Макет не содержит «Возраст персонажа». В приложении поле появляется при adult.
**Цель:** либо завести состояние в макете, либо визуально вписать поле в ту же сетку 8px (сейчас выпадает из ритма карточек выбора).

### GAP-016 — журнал / лента событий empty

Макет журнала (`2181:1241`) — всегда 4 записи. Главная: «Пока нет записей» уже есть и совпадает с empty в `ActivityLogCard`. Ок. На `/game/activity` пустой список нужно сверить отдельно (не снимали live empty).

## P2 — отступы, сетка 8px

Контентный padding 32 совпадает с макетом. Ломает ритм **сложение gap колонки + margin секций**.

Измерения live (округление до 8):

| Место | Макет | Приложение | Цель |
|---|---|---|---|
| Действия: табы → фильтры | 16 | 44 (32 content-gap + 12 margin-top) | **16** |
| Действия: фильтры → сетка карточек | 24 (факт 25) | 32 | **24** |
| Действия: gap табов | 8 | 8 | ок |
| Действия: gap карточек в ряду | 12 | 12 | ок |
| Действия: gap рядов | 16 | 12 | **16** |
| Магазин: gap табов | 8 | 12 (`.shop-page > .tabs`) | **8** |
| Магазин: табы → следующий блок | 16 | 16 | ок |
| Магазин: фильтр → сетка | 16 | ~16, но фильтр стоит **после** заголовка «Еда» | порядок, см. GAP-021 |
| Недвижимость: summary → «Варианты» | 32 | 16 | **32** |
| Недвижимость: ряды карточек | 32 / 12 | 32 / 12 | ок |
| Главная: KPI-ряд → превью | 16 | 16 (`.main-page` gap) | ок |
| `.dashboard-shell__content` gap | — | **32** | не должен суммироваться с margin секций; для page-стека достаточно 16 |

### GAP-020 — actions: двойной вертикальный ритм

**Код:**
- `DashboardLayout.scss` — `gap: var(--space-component-padding)` → 32
- `global.scss` `.action-filters` — `margin: $space-3 0 $space-2` (12 / 8)

Итог 44px между табами и фильтрами вместо 16.

**Цель:** один источник вертикального ритма. Page stack 16. Убрать margin у `.action-filters`. Фильтры в макете — панель 80px с внутренним padding 8, поля 64.

### GAP-021 — магазин: порядок блоков

Макет `2275:4352`: заголовок → табы → **фильтр градации** → заголовок каталога «Еда» → сетка.
Приложение: заголовок → табы → «Еда» + описание → **фильтр** → сетка.

Фильтр в макете на `y: 196` (сразу под табами), каталог на `y: 300`. Сейчас визуально «дыры» между табами и карточками больше, потому что заголовок секции вставлен выше фильтра.

**Код:** `src/pages/game/shop/index.vue`

### GAP-022 — отрицательные margin у intro-текстов

`shop-page__intro` и `housing-page__intro` — `margin: -8px 0 0`. Это костыль против 16px page-gap. В макете заголовок 24/29 + 8 до подзаголовка.

**Цель:** heading+subtitle как одна группа с внутренним gap 8, внешний gap 16 до следующего блока. Без отрицательных margin.

### GAP-023 — календарь обрезает четверг

Фрейм `2322:5336`: колонка «Чт» частично за правым краем кадра — в макете это горизонтальный overflow контента, не clip шелла.
Приложение с `overflow-x: hidden` на content отрежет день. Нужен горизонтальный скролл ряда дней **внутри** блока, не clip колонки.

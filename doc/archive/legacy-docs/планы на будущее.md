Порт SaveRepository → async-first: сейчас SaveRepository.save синхронный, а persistSave в save-commands уже async. Привести порт к Promise<void> и обновить LocalStorageSaveRepository — это откроет путь к remote persistence без переписывания.

Стандартизировать effect application pattern: сейчас каждый фасадный метод game-store (applyWorkShift, changeCareer, startEducationProgram) применяет effects по-разному. Выработать единый паттерн: application возвращает typed effect payload → store-level функция applyEffect(payload) делает мутации.

useActions всё ещё мутирует state напрямую: composable вызывает walletStore.spend(), statsStore.applyStatChanges() и т.д. По канону application-first — composable должен получать effect payload из application и передавать его в store-метод (или game-store) для применения. Сейчас composable одновременно является и orchestrator-ом, и effect applicator-ом.

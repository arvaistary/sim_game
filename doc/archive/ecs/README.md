В этой папке собрана вся документация о миграции проекта Game Life на ECS (Entity-Component-System) архитектуру.

## 📚 Обзор

ECS архитектура обеспечивала чистое разделение данных (Components), логики (Systems) и идентификаторов (Entities), что значительно улучшало масштабируемость и поддерживаемость кода.

**Важно:** Список Phaser-сцен `../core/SCENES_REFERENCE.md` больше не актуален — проект перешёл на Nuxt 4 + Vue 3.

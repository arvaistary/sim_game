# Справочник страниц

**Последнее обновление:** 22 июля 2026

Nuxt использует файловый роутинг из `src/pages/`. Отдельного динамического
роутера `src/nuxt-pages/` в проекте нет.

## Точка входа

| URL | Файл |
|---|---|
| `/` | `src/pages/index.vue` |
| `/game` | `src/pages/game/index.vue` |

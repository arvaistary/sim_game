# Чеклист code review

- [ ] Scope diff соответствует запрошенной задаче.
- [ ] Критерии приёмки и наблюдаемое поведение выполнены.
- [ ] Прослежены callers, переходы состояния, persistence и error paths.
- [ ] Соблюдены правила архитектуры и технологического адаптера.
- [ ] Не осталось ненужных абстракций, дублирования, dead code или speculative optimization.
- [ ] Public contracts и совместимость сохранены либо явно одобрены.
- [ ] Тесты и целевые проверки покрывают изменённое поведение.
- [ ] Baseline failures задокументированы отдельно.
- [ ] Feedback ручного QA обработан или явно зафиксирован.
- [ ] Findings аудита имеют корректные статусы и доказательства проверки.
- [ ] Browser и security checks запущены, если применимо; недоступные adapters зафиксированы.
- [ ] Shell verification mode зафиксирован, если проверки затрагивал fallback.

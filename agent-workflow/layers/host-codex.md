# Адаптер host-среды Codex

Codex использует переносимый разговорный workflow как workflow репозитория по умолчанию.

## Entry point

Файл `AGENTS.md` репозитория указывает на:

- `agent-workflow/README.md`;
- выбранный технологический адаптер;
- выбранный проектный адаптер;
- канонические навыки в `agent-workflow/skills/` или тонкие host-local wrappers.

## Поведение в разговоре

- Начинайте с discovery и baseline.
- После проверки задавайте только существенные вопросы.
- Управляйте обычными переходами, не ожидая команд для смены фазы.
- После реализации остановитесь на Manual QA и дождитесь проверки пользователя.
- Используйте язык пользователя в вопросах и отчётах о фазах.

## Scope и разрешения

Full access означает, что агент может работать в разрешённом workspace; это не означает наличие прав Windows Administrator или разрешения воздействовать на внешние системы.

Не создавайте и не вызывайте workflow-артефакты другого инструмента или эквивалентное planning state, если пользователь явно не запросил этот workflow.

Не создавайте branches, worktrees, commits, merges, pull requests, messages, deployments или внешние записи, если это не запрошено или не требуется явно принятой процедурой проекта.

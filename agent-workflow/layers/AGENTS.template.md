# <Название проекта> — entrypoint Codex

Следуйте переносимому workflow из `agent-workflow/README.md`.

Перед работой в репозитории прочитайте технологический и проектный адаптеры целевого проекта. Используйте host-local wrappers для канонических навыков task-flow, audit, code-review и environment.

Прочитайте путь к активному состоянию задачи и каталогу истории из проектного адаптера. Возобновляйте активный checkpoint после прерывания, обновляйте его на границах фаз и сохраняйте историю после закрытия.

Начинайте с discovery и baseline, задавайте только существенные вопросы, вносите минимальное безопасное изменение, останавливайтесь на Manual QA, затем проводите audit и review после подтверждения пользователя.

По умолчанию не создавайте и не вызывайте workflow state другого инструмента. Останавливайтесь перед destructive-действиями, external side effects, работой с credentials, изменением public contract, существенно отличающейся архитектурой или новой restrictive policy.

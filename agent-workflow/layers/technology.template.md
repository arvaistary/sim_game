## Команды проверки

| Назначение | Команда | Когда требуется |
|---|---|---|
| Unit/integration tests | `<command>` | изменения поведения |
| Type check | `<command>` | изменения типизированного кода |
| Lint/style | `<command>` | изменения исходного кода или стиля |
| Build | `<command>` | изменения build/config/deployment |
